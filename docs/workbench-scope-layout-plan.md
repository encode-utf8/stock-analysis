# 工作台模块分组布局方案（当前标的视图 / 持仓与全局工具）

## 需求来源

用户反馈：与当前基金 / 股票无关的功能（例如持仓、日报等）应当与针对当前标的的功能区分开来，需要重新构建协调的 UI 布局。

## 现状问题

- 顶部「功能模块」是单一横向菜单，个股 14 项 / 基金 16 项 chips 混在一起；勾选多个后，模块在内容区按同一顺序纵向堆叠；
- 随当前标的切换的视图（行情、K 线、资讯、AI、对话、复盘）与账户级 / 独立工具（持仓、回测、预警、日报、数据源、对比、定投）交错排列，用户需要长距离滚动才能到达目标内容，也容易误以为持仓 / 日报会随当前标的切换；
- 模块栏可勾选列表过长，横向滚动才能看全。

## 目标

1. 每个工作台的模块按「是否随当前标的切换」拆成两组：**当前标的** 与 **持仓与全局工具**；
2. 顶部模块栏升级为「分组切换 + 本组模块 chips」：两组各自独立勾选、独立展示，互不干扰；
3. 分组为空时给出可操作空态（一键启用该组默认模块：行情概览 / 基金档案 / 我的持仓组合 / 持有基金）；
4. 切换当前标的（自选点击、持仓 / 持有列表点击）时自动回到「当前标的」分组，并在该组为空时启用默认模块，保证切换结果可见；
5. 不改动任何模块的取数、缓存与数据源降级行为。

## 分组依据（客观标准：面板是否依赖当前标的代码）

### 个股工作台

| 分组 | 模块 |
| --- | --- |
| 当前标的（8） | 行情概览、K 线走势、技术指标、资讯搜索、周期内 AI 分析、对话助手、历史会话时间线、历史复盘 |
| 持仓与全局工具（6） | 我的持仓组合、策略回测、数据源与调度、预警中心、AI 股市日报、系统可观测性 |

### 基金工作台

| 分组 | 模块 |
| --- | --- |
| 当前标的（8） | 基金档案、净值走势、当日行情、持仓分析、回撤与风险指标、AI 分析、对话助手、历史复盘 |
| 持仓与全局工具（8） | 持有基金、基金对比、基金组合分析、定投回测、行业资讯、风格因子分析、预警中心、AI 基金日报 |

判定说明：`行情概览`、`K 线走势`、`资讯搜索`、`对话助手`、`历史复盘` 等由工作台注入当前代码并随之刷新；`我的持仓组合`、`预警中心`、`AI 股市日报`、`系统可观测性` 与标的无关；`策略回测`、`基金对比`、`基金组合分析`、`定投回测`、`行业资讯`、`风格因子分析` 自带代码输入、不随当前标的联动，归入工具组并保持既有行为。

## 设计与改动

- 模块选项新增 `scope` 字段（`"target" | "global"`）与分组定义 `MODULE_SCOPES` / `FUND_MODULE_SCOPES`，并提供按分组取选项、生成分组可见性集合的辅助函数；
- `ModuleMenuBar` 增加分组切换行：`role="tablist"` + `role="tab"`（`aria-selected`），每个分组显示「本组已启用 / 本组总数」，右侧保留说明文案与按组的全选 / 清空；
- 两个工作台新增 `activeScope` 状态：chips、模块渲染顺序、全选 / 清空都按当前分组计算，另一分组的勾选状态原样保留；
- 内容区空态区分分组并给出一键启用默认模块的按钮；
- `handleWatchlistSelect` 与持仓 / 持有列表点击统一切换到「当前标的」分组；
- 顺带修正工作台副标题，明确两组语义。

## 改动范围

- 修改：`src/components/panels/FunctionOptionsSidebar.tsx`、`src/components/panels/fund/FundOptionsSidebar.tsx`、`src/components/panels/ModuleMenuBar.tsx`、`src/components/workbench/StockWorkbench.tsx`、`src/components/workbench/FundWorkbench.tsx`；
- 测试：新增 `tests/module-scope.test.ts`（分组数据与菜单渲染冒烟）、`tests/e2e/module-scope.spec.ts`（分组切换、空态、勾选保留）；更新 `tests/e2e/holdings-quick-switch.spec.ts`（改到新分组下操作并验证自动回到标的组）；
- 文档：本方案、`docs/checklists/12-feature-workbench-scope-layout.md`、根 `checklist.md` 与 `README.md` 同步。

## 非目标

- 不调整各模块的取数、缓存与降级策略；
- 不做分组的跨会话持久化（与模块勾选状态保持一致，刷新恢复默认）；
- 不改左侧自选栏、顶部工作台切换与实时行情条（实时行情条是自选池状态条，与标的无关但与两组都相关，保持在模块栏上方常驻）。

## 测试与验收

- 单测：两组模块划分完整且无重复；菜单渲染只出现当前分组的 chips，分组计数正确；
- 端到端：默认进入「当前标的」组 → 切到「持仓与全局工具」勾选持仓 / 日报 → 切回「当前标的」，两组勾选互不影响；持仓列表点击后自动回到「当前标的」组并展示盘面模块；
- 回归：`typecheck` / `lint` / `test` / `build` / `test:e2e` 全绿。

## 风险与遗留

- 分组切换本质是视图过滤，`enabledModules` 仍是同一份扁平状态，无数据迁移；
- 默认分组为「当前标的」，既有入口（自选点击、代码查询）后的可见内容与改动前一致；
- 既有端到端用例中涉及全局模块的用例需先切分组，已在用例内显式切换。
