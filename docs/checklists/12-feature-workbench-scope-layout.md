# 12 工作台模块分组布局验收清单

- 分支：`feature/datasource-failure-ux`（沿用当前工作分支）
- 关联方案：`docs/workbench-scope-layout-plan.md`
- 目标：把「随当前标的切换」的模块与「持仓 / 全局工具」在顶部模块栏与内容区彻底分开，并保证切换标的后可见结果。
- 状态：已完成（2026-09-22），等待用户确认后提交。

## 验收项

### 分组定义与菜单

- [x] 模块选项新增 `scope` 字段，`MODULE_SCOPES` / `FUND_MODULE_SCOPES` 给出分组名与说明
- [x] 分组划分完整且不重复：个股 8 + 6，基金 8 + 8
- [x] `ModuleMenuBar` 渲染分组 tablist（`aria-selected`）与「本组已启用 / 本组总数」计数
- [x] 模块 chips 只展示当前分组的模块；全选 / 清空只作用于当前分组
- [x] 模块栏右侧按分组展示说明文案（当前标的组显示当前标的）

### 工作台布局

- [x] 两个工作台新增 `activeScope` 状态，默认「当前标的」
- [x] 内容区只渲染当前分组已勾选的模块，另一分组勾选状态保留
- [x] 分组为空时给出空态与「启用「模块名」」按钮
- [x] 自选点击、持仓 / 持有列表点击后自动回到「当前标的」分组，必要时启用默认模块
- [x] 工作台副标题说明两组语义
- [x] 各模块取数、缓存与降级行为未改动

### 测试

- [x] 单测：分组划分完整性、菜单按分组渲染与计数
- [x] 端到端：分组切换与勾选互不影响
- [x] 端到端：持仓列表点击后自动回到「当前标的」分组并展示盘面模块
- [x] 回归：`typecheck` / `lint` / `test` / `build` / `test:e2e` 全绿

### 文档

- [x] 方案文档 `docs/workbench-scope-layout-plan.md`

## 验证方式

```powershell
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm test
corepack pnpm build
corepack pnpm test:e2e
```

## 通过标准

- 顶部模块栏可一键在「当前标的」与「持仓与全局工具」之间切换，chips 与计数只反映当前分组；
- 两个分组的勾选状态互不影响，切回后原样保留；
- 切换当前标的后自动回到「当前标的」分组，且该分组不会因为从未勾选而空白；
- 全部校验命令通过，无新增 lint 告警。

## 风险与遗留

- 分组状态不跨会话持久化（与既有模块勾选一致）；
- 实时行情条（自选池推送）与免责声明保持常驻，不随分组切换。
